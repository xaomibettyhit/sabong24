# Hollywood Actress Info Bot

A Telegram bot for looking up Hollywood actress profiles, films, and awards.

## Features
- Search any actress by name
- Browse by category (A-List, Oscar Winners, New Generation)
- Random actress discovery
- Full profile with films, awards, and bio

## Deployment (Railway)
1. Push this repo to GitHub.
2. Create a new Railway project from the repo.
3. Set environment variable: `TELEGRAM_BOT_TOKEN`
4. Deploy.

## Updating the Database
Edit `data.py` on GitHub. Railway will auto-redeploy.
